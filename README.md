# 🏠 Chá de Casa Nova

Aplicação web desenvolvida para organizar uma lista de presentes para um chá de casa nova.

O projeto permite que os convidados visualizem os presentes disponíveis, filtrem por categorias e reservem itens escolhidos. Também possui gerenciamento de reservas, controle de presentes reservados e uma área para envio de recados.

## ✨ Funcionalidades

- 🏡 Página inicial com informações do evento
- 💕 Seção sobre os anfitriões
- 🎁 Lista de presentes
- 🔎 Filtro por categorias
- 📄 Paginação dos presentes
- 🎀 Reserva de presentes
- 🔐 Controle para evitar reservas duplicadas
- 👥 Sistema de cotas para presentes com múltiplas contribuições
- ❌ Cancelamento de reserva
- 📊 Barra de progresso dos presentes reservados
- ✅ Confirmação de presença dos convidados
- 💌 Envio e exibição de recados
- 📱 Interface responsiva

## 💡 Sobre o projeto

Este projeto foi desenvolvido para uso em meu chá de casa nova, com o objetivo de criar uma experiência simples para que os convidados possam consultar a lista de presentes e informar suas escolhas.

Durante o desenvolvimento foram implementados conceitos de desenvolvimento full-stack, incluindo criação e consumo de API REST, integração com banco de dados, autenticação, gerenciamento de reservas, paginação, filtros e desenvolvimento de uma interface responsiva.

## Observação

O projeto foi desenvolvido exclusivamente para o meu chá de casa nova, com o objetivo de facilitar a organização da lista de presentes e a interação com os convidados. Por esse motivo, as instruções para execução em ambiente local não foram disponibilizadas, já que a aplicação foi criada para um uso específico.
